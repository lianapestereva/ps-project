# Программа для создания автоматически заполняемого резюме

## Описание
Эта программа позволяет получить информацию о вас и ваших достижениях с помощью GitHub API и сохранить её в текстовый файл. Информация включает ваши личные данные и список ваших публичных репозиториев. Затем программа запускает веб-сервер, на котором выкладывает данную информацию.

## Требования
Python 3.6+

## Как работать?
1. Установка библиотек командой `pip install -r requirements.txt`.
2. Получение токена с GitHub. GitHub >> Settings >> Developer Settings >> Personal Access Tokens >> Tokens (classic) >> Generate New Token. Выбрать scopes "user" и "project". Копируем получившийся токен.
3. Создайте файл ".env" в папке проекта. В файле создайте переменную "TOKEN" и присвойте ей значение токена, полученного на  GitHub. Там же создайте переменную "GIT_USERNAME" и присвойте ей значение своего имени пользователя.
4. Запускаем программу при помощи команды `python main.py`
5. Результат в "человекочитаемом" виде будет сохранен в файле ans.txt, а перейдя по ссылке в терминале можно будет уведеть, как это выглядит на сайте
